Raw JSON payload, Ed25519-signed with this device's public key included so any receiver can verify it independently -- for a custom integration instead of ntfy. Editing this by hand switches delivery back to the raw JSON format.

Device Offline Severity

A device going offline is scored by its role -- a router losing connectivity usually means the whole segment lost its default gateway, which is a much bigger deal than one endpoint disappearing.

SNMP Default-Community Exposure

Applies to any device found responding to a default SNMP community string ("public"/"private") -- whether that's its primary credential or an extra exposure alongside a real one. Unlike an offline event, this is a standing gap that persists until fixed, so it isn't split by device role.

SNMPv3 Available But Unused

Applies to any device confirmed to have a real SNMPv3 engine (its snmpEngineID answers) but is currently being managed over plaintext v2c instead -- a hardening opportunity, not an active exposure like a default community string, so this defaults lower.
