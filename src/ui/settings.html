SNMP v3 Identities

Each identity is tried against every device (strongest security protocol first) until one succeeds. No protocol selection needed -- NetLanvas discovers the correct pairing automatically per device. Tried before any SNMP v2c community strings (see Environment Strings below).

Note: With more than one identity configured, devices will see (and may log) authentication attempts using identities that turn out not to be theirs, before the correct one is found. This is expected during discovery, not a sign of a problem -- once a device's correct identity is found, it is remembered and tried first from then on.
